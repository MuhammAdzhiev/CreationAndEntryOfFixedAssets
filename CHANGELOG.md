## \[2.0.0]

### Добавлено

* Два режима загрузки из Excel:

  * создание элементов справочника **«Основные средства»** и связанных **инвентарных номеров ОС**;
  * создание и проведение документов **«Ввод начальных остатков ОС»** для уже существующих объектов.
* Заполнение параметров документов из формы: организация, КПС, порядок погашения стоимости и сведения о первичных документах.
* Чтение десяти столбцов Excel: основное средство, инвентарный номер, количество, балансовая стоимость, амортизация, остаточная стоимость, счёт учёта, ЦМО и две даты.
* Нормализация инвентарных номеров: удаление пробелов и табуляций, дополнение коротких номеров нулями слева.
* Поиск либо создание сотрудников и ЦМО, если необходимых элементов нет в выбранной организации.
* Вывод результатов фоновой загрузки: количество созданных ОС, инвентарных номеров и документов, число пропущенных строк и ошибок с номерами строк Excel.
* Отображение прогресса длительной операции.

### Изменено

* Загрузка выполняется в фоне через механизм дополнительных обработок БСП. Для завершённой операции запрашивается и обрабатывается пользовательский результат.
* Создание ОС и его инвентарного номера объединено в одну транзакцию.
* Создание сотрудника/ЦМО (при необходимости), запись документа ввода остатков, загрузка проводок и проведение выполняются в рамках одной транзакции. При ошибке транзакция отменяется, а кэши сотрудников и ЦМО очищаются.
* Кэш существующих документов обновляется только после успешной фиксации транзакции.

### Исправлено

* Ошибка отсутствующего поля "Режим" при обработке результата фонового задания.
* Ошибка отсутствующего поля "Текст", возникавшая при повторной попытке создать ввод остатков для уже обработанных ОС.
* Обработка повторных запусков: ранее созданные инвентарные номера и документы распознаются и пропускаются, а не создаются заново.
* Проверка флага "Отказ" после загрузки бухгалтерских проводок: при отказе вызывается исключение вместо продолжения проведения.
* Обработка ошибок преобразования чисел и дат Excel: некорректные значения вызывают диагностическое сообщение, а не незаметно заменяются значением по умолчанию.
* Сообщения об ошибках формируются с указанием строки Excel без повторного добавления номера во вложенных обработчиках исключений.

### Оптимизировано

* Предварительное получение уже существующих документов ввода остатков одним запросом по инвентарным номерам файла с сохранением результатов в кэше.
* Кэширование поиска счетов, ИФО, инвентарных номеров, ЦМО и сотрудников для уменьшения числа повторных обращений к базе данных.
* Убраны ненужные повторные проверки наличия реквизитов в метаданных для конфигурации, на которую рассчитана обработка: используются прямые присваивания.
* Удалены лишние возвращаемые поля и промежуточные вычисления, не использовавшиеся вызывающим кодом.
